# 01. 매일 댕생활 (`/treasure-mine/` · `/growth/` · `/challenge/`) + 굿즈 공모전 (`/goods-contest/`) — 기능 전수 분석

> 로컬 분석 문서 (배포 X). 협업자 웹 화면(`GrowthHub`) 기준. 우리 로컬 시안은 앱 모드에서만 `DailyLifeApp` 으로 바뀐다.
> `/growth/` · `/challenge/` 는 같은 GrowthHub 를 보여 주고 검색 노출 안 함(canonical `/treasure-mine/`).

## 1. 화면 순서 (GrowthHub)
1. **머리** — 관리자 문구(content.hero): "DAENGDABANG TREASURE MINE" · "오늘 기능 운영 중" · "매일 하나씩, 우리 아이 돌봄 보물을 모아요" + 바로가기: 오늘의 보물(`#today-treasure`) · 굿즈 500명 공모전(`/goods-contest/`) · 동네 돌봄 찾기(`#local-care-finder`, 관리자 표시 시) · 준비 중인 혜택(`#growth-programs`, 관리자 표시 시)
2. **오늘** — "TODAY'S TREASURE · 오늘 바로 할 수 있는 돌봄부터" → 불러오는 중 / 회원: 회원 대시보드 / 비회원: 3단계 안내
3. **기록 나누기** (모두)
4. **맞춤 상품 연결** (모두)
5. **굿즈 공모전 소개** (`#goods-contest`)
6. **확장 계획 4단계** (`#community-commerce-roadmap`)
7. **동네 돌봄 찾기** (관리자 표시 시)
8. **준비 중인 혜택** (관리자 표시 시)
9. **안심하고 이용하세요** (관리자 표시 시)

판단 값: 회원 = user 있음 · 반려견 있음 = pets 1마리 이상 · AI 기록 있음 = **어느 반려견이든** 분석 기록 있음(대시보드에서 고른 아이와 무관)

## 2. 비회원
- **3단계:** 01 출근도장("한국 시간 기준 하루 한 번…") · 02 작은 돌봄("산책과 눈 상태 확인처럼…") · 03 변화 기록("AI 분석과 지난 기록을…")
- 안내 "로그인하면 오늘 기록이 계정에 이어져요" / "비회원도 아래 성장 프로그램과 운영 정책은 먼저 둘러볼 수 있습니다."
- 로그인하고 시작 → `/auth/login/?redirect=%2Ftreasure-mine%2F` · 처음이라면 회원가입 → `/auth/signup/?redirect=%2Ftreasure-mine%2F`
- 기록 나누기: "로그인 후 AI 기록 공유"(로그인) · "친구에게 보물광산 초대"(가능)
- 맞춤 상품: "돌봄을 살펴본 뒤 쇼핑으로 자연스럽게 이어가세요" → 전체 상품 둘러보기 `/products/` · 추천 셀렉트 보기 `/best/`
- 혜택: 모든 버튼 "로그인 후 관심등록" → `/auth/login/?redirect=%2Ftreasure-mine%2F%23growth-programs`
- 비회원은 출근 · 할 일 서버 요청 없음

## 3. 회원 — 대시보드 (MemberAiDashboard)
- 불러오기: `GET /api/v1/daenglab/wallet/attendance` + `GET /api/v1/daenglab/engagement` (토큰 필요)
- **머리:** 반려견 사진(없으면 아이콘) · "PERSONAL AI DASHBOARD" · "{반려견}와 오늘 뭐 하지?"(없으면 "{회원}님, 오늘 뭐 하지?") · "출근도장부터 산책·분석·추천까지 한 번에 이어가세요." · **내 아이 리포트** → `/my-pet/`
- **아이 선택** (2마리 이상): 화면 안에서만 바뀜(서버 요청 없음). 머리 · 오늘 AI 분석 · 사진 분석 링크 · 최근 건강 변화 · AI 추천이 바뀜. 출석 · XP · 할 일은 **계정 단위**라 안 바뀜.
- **오늘 상태 4칸:**
  | 칸 | 값 | 설명 |
  |---|---|---|
  | 오늘 건강 루틴 점수 | min(100, 52 + 완료 수×12)점 | "의료 점수가 아닌 오늘 돌봄 완료율" |
  | 오늘 AI 분석 | 오늘 분석했으면 "완료", 아니면 "아직" | "최근 {날짜}" / "첫 사진 분석을 시작해 보세요" |
  | 이번 주 출석 챌린지 | n / 7 | "{n}% 진행" |
  | 오늘 산책 | 산책 할 일 완료 시 "20분 완료" | "오늘의 산책 XP가 반영됐어요" / "무리하지 않는 범위에서 시작하세요" |
  (완료 수 = 끝낸 할 일 + 오늘 출근 + 오늘 분석)
- **오늘 해야 할 일** ("작게 하나씩 완료해요" · {n}/4 — 4는 고정값):
  - 서버가 주는 할 일 버튼(ID `walk_20` · `eye_check`, **제목 · XP는 서버가 정함**, 설명은 안 보여 줌) — "{제목} +{xp}XP" → `POST /api/v1/daenglab/engagement/tasks/{id}/complete` → 초록 완료 · XP/레벨 갱신 (**코인 없음 · 완료 알림 없음**)
  - 마지막 줄 항상 "사진 건강 분석" → `/pet-lens/?profile={id}` (없으면 `/pet-lens`)
- **레벨:** "LEVEL n" · 3 미만 "건강 새싹", 이상 "우리 아이 지킴이" · XP 막대(레벨당 100XP 가정) · "{xp} XP" / "다음 레벨 {n} XP" · 최근 건강 변화(분석 상태, 없으면 "첫 분석을 기다리고 있어요") · **AI 추천** → 반려견 있으면 `/#recommend`(고민 키워드로 문구: 눈 보호 산책 안전용품 / 피부·발바닥 관리용품 / 식단·체중 먹거리 / 활동량·놀이 장난감 / 맞춤 상품), 없으면 `/mypage/?profile=required#pet-profiles` "프로필 등록 후 맞춤 추천 받기"
- **진행률:** 이번 주 출석 n/7 · 이번 달 AI 체크 n/5
- **출근도장 카드** (AttendanceStampCard): "매일 출근" · "{n}일 연속" · "오늘도 우리 아이 돌봄 출근!" · "하루 한 번 도장을 찍으면 **코인 {2}개**가 서버 지갑에 바로 지급돼요." · "{n}C 보유" · 최근 7일(발바닥/빈칸) · 버튼 "도장 꾹!"(누르는 중 "꾹…", 완료 "출근 완료")
  - 누르면 `POST /api/v1/daenglab/wallet/attendance/claim` → 지갑 이벤트(`ddb:daenglab-wallet`) → 할 일 다시 불러옴 → 처음이면 +1 코인 터짐 + "출근 완료! 댕다방 연구소 코인 2개가 지급됐어요." / 이미면 "오늘 출근도장은 이미 찍혀 있어요. 내일 다시 만나요!"
  - 아래 항상: "도장 날짜와 보상은 한국 시간 기준으로 서버가 확인하며, 같은 날 여러 번 눌러도 한 번만 지급됩니다."
  - 못 불러오면 "출근도장을 불러오지 못했어요" + 다시 불러오기
- **오류 띠:** 서버 문구 또는 "오늘의 AI 대시보드를 불러오지 못했습니다." + 다시 시도

| 상태 | 달라지는 점 |

## 4. 다른 구역

  - 회원: `GET /api/v1/growth/interests/me` → 미등록이면 버튼 → 동의 폼("(필수) …회원 계정에 등록된 이메일로 받는 데 동의" · 수집 항목/목적/보유 기간/거부 안내 · 개인정보처리방침) → 관심등록 저장 `POST /api/v1/growth/interests {program_id, consent_to_contact:true}` → "관심등록을 저장했어요"/"이미 관심을 남겨두셨어요" + 접수번호 · 등록됐으면 "관심 등록 취소" `DELETE /api/v1/growth/interests/{id}` (확인창 없음)

## 5. 굿즈 공모전 전체 화면 (`/goods-contest/`)
- 관리자 문구 · 이벤트 `growth_hub_viewed{surface:goods_contest}` · 머리 영상 · 상태(기간 종료/운영자 종료/D-n/90일 공모 진행 중) · "회원·비회원 모두 참여" · 기간 · 01~04 단계
- 굿즈 21개 카드: 이미지 · 예상 펀딩가 · 이름 · 설명 · {n}/500명 · "500명 달성"/"{n}명 남음"
- 안전 안내(결제 방식 · 1P=1원 · 1댕코인=100원 · 에스크로) · 에스크로 안내 보기 `/legal/escrow/`
- 집계 `GET /api/v1/growth/goods-contest`(로그인 불필요)
- 버튼 상태: 불러오는 중 → 공모 종료(최종 선택 완료/공모 종료) → 비활성 품목 → **비회원: "이메일 확인 후 선택" + "회원은 로그인하고 바로 선택"** → 회원/인증된 비회원: "이 굿즈 선택"/"선택 취소"
- 회원: `GET …/me` · `PUT/DELETE …/items/{id}/selection` (토큰) / 인증 비회원: `…/guest/…` (헤더 `X-Goods-Guest-Token`, 저장 `ddb.goodsContest.guestToken`)
- **비회원 이메일 인증:** 이메일 → `POST …/guest/email-verifications` → 6자리 → `POST …/{id}/confirm` → 토큰 저장 + 처음 고른 굿즈 자동 선택
- 안내: "선택을 저장했어요. 주문·예약·결제는 발생하지 않았습니다." 등 · 이벤트 `goods_contest_selection_completed`

## 8. 발견한 문제 (협업자 화면)
1. 출근도장 요청 실패 시 "이미 찍혀 있어요"가 잘못 뜸(오류 띠와 동시에)
2. 지갑 이벤트를 이 화면에서 듣는 곳이 없음(연구소 화면만 들음)
3. 반려견 없는 회원의 AI 추천 링크가 `?profile=required` — 마이페이지는 `petProfile=required` 를 읽음 → **등록 유도가 안 켜짐**
4. 토큰 없는 사용자: 다시 불러오기 무반응
5. 토큰 만료 시 대시보드에 다시 로그인 링크 없음
6. 관리자가 숨긴 구역으로 가는 링크가 남음(확장 계획 04 · 혜택의 후보 찾기)
7. 할 일 4/4 고정 · 레벨당 100XP 가정
