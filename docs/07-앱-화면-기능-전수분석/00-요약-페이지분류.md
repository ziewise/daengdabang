## 2. 코인 · 포인트 흐름 (화면 배치에 중요)

| | 어디서 | 얼마 |
|---|---|---|
| 받기 | 가입 후 이메일 인증 (마이) | 20C |
| 받기 | **매일 출근도장 (댕생활)** | 2C |
| 받기 | 오늘 돌봄 챌린지 (내역 이름만 있음) | ? |
| 받기 | 구매 확정 적립금 → 전환 (마이) | 1,000P → 10C |
| 받기 | 분석 실패 자동 환급 (연구소) | 10C |
| **쓰기** | **행동·소리·건강 영상 분석 (연구소)** | **10C / 회** |
| XP | 오늘 할 일 (댕생활) | 서버가 정함 (코인 X) |

→ **댕생활에서 모으고 → 연구소에서 쓰는 구조.** 지갑은 마이에 있고, 연구소 분석 화면에서도 잔액이 보임. 출근도장 = 연구소로 들어가는 동기.

## 3. 이번 분석으로 새로 알게 된 것 (분류에 영향)

1. **"성장" 이라는 화면은 원래 없다** — 웹의 회원 대시보드 한 덩어리에 출근 · 할 일 · XP · 레벨 · 진행률이 **모두 "오늘" 구역 안에** 들어 있음. 우리 시안의 성장 탭(금속 카드 · 목표)은 이걸 쪼갠 것 → **사용자 판단대로 오늘 탭에 있어야 맞음.** 웹의 나머지(기록 나누기 · 맞춤 상품)는 "성장"이 아니라 "공유 · 쇼핑 연결".
2. **댕다방 연구소는 콘텐츠가 아니라 "회원 전용 AI 분석 도구"** — 비회원은 자물쇠 한 장, 회원도 아이 등록 · 견종 확인이 끝나야 쓸 수 있고, 영상 분석은 코인을 씀. 결과는 **우리 아이(`/my-pet`) 리포트**로 이어짐.
3. **협업자의 앱 홈(`/app/`)은 이미 "AI 케어 홈"** — 회원에게 아이 선택 + 사진 분석 · 주간 리포트 · 행동·소리 분석 카드 3개 + CareTalk 열기를 보여 줌. 즉 협업자도 앱 홈 = 우리 아이 AI 케어로 생각하고 있음.
4. **우리 아이(`/my-pet`)는 어디에도 확실한 자리가 없음** — 상단바에선 "댕생활 > 우리 아이 기록"과 "연구소 > 건강 변화 리포트" 두 곳, 마이 메뉴 "건강 기록", 앱 틀에서는 마이 탭 소속.
5. **이벤트성 기능은 3곳에 흩어짐** — 굿즈 공모전 · 준비 중 혜택(관심등록) · 오늘의 댕주제(댕자랑).
6. **동네 돌봄 찾기가 2곳** — 댕생활 동네 탭 + 케어톡 답변 안 "가까운 후보 보기"(같은 서버 주소).
7. 반려견 등록은 **마이페이지 한 곳**에서만 가능 — 연구소 · 댕생활 · 케어톡 · 앱 홈이 모두 그리로 보냄.

## 4. 페이지 분류 제안

### 추천안 — "홈 = 우리 아이 AI 케어" (연구소를 홈으로)

| 탭 | 역할 | 들어갈 것 | 로그인 전 | 로그인 후 |
|---|---|---|---|---|
| **홈** | 우리 아이 AI 케어 허브 | 아이 카드(선택) · **댕다방 연구소 ①사진 ②행동·소리** · 주간 리포트(`/my-pet`) · 케어톡 · 코인 잔액 · 오늘 출근 여부 한 줄 | 서비스 소개 + 예시 결과 미리보기 + 가입 | 협업자 `/app/` AI 케어 요약을 시안 디자인으로 |
| **댕생활** | 매일 습관 · 혜택 | **오늘**(출근도장 · 할 일 · 레벨/XP · 진행률 · 사진 분석 바로가기 · 맨 아래 기록 나누기 + 맞춤 상품) · **이벤트**(굿즈 공모전 · 준비 중 혜택 관심등록) · **동네**(동네 돌봄 찾기) · **안내**(확장 계획 · 운영 기준) | 오늘 = 3단계 + 스티커 체험 + 로그인 / 나머지 3탭은 거의 그대로 볼 수 있음 | 오늘 = 회원 대시보드 |
| **댕다방** | 커뮤니티 · 콘텐츠 | **댕자랑**(피드 · 오늘의 댕주제) · (나중) 돌봄 비교 매거진 `/reviews` · 커뮤니티 `/community` | 피드 보기 가능 | 올리기 · 팔로우 · 응원 |
| **쇼핑** | 웹 쇼핑 그대로 | `/` + 웹 상단바 | 같음 | 맞춤 추천 |
| **마이** | 계정 · 아이 · 지갑 · 주문 | 마이페이지 · 반려견 프로필 · 지갑 · 주문 · 설정 · 고객센터 · 약관 | 로그인/가입 | 그대로 |
| 케어톡 | 어디서나 상단 버튼 → 서랍 | | 질문 가능 | 아이 선택 |

- 장점: 탭마다 성격이 분명(케어 / 습관 / 커뮤니티 / 쇼핑 / 계정). 협업자의 앱 홈 방향과 같음. 비회원이 홈에서 "무엇을 해 주는 앱인지" 바로 봄. 댕다방 탭은 비회원도 다 볼 수 있는 화면만 남음.
- 단점: 앞서 정한 "댕다방 = 댕자랑 + 연구소"를 바꿔야 함. 댕다방 탭이 당분간 댕자랑 하나뿐(매거진 준비 전).

### 유지안 — 지금 구조 (댕다방 = 댕자랑 + 연구소)
- 홈은 시안(ClassicHome) 그대로, 연구소는 댕다방 탭 하위 줄.
- 바꿀 것: 연구소 비회원 화면을 자물쇠 대신 **소개 + 예시 결과 + 가입** 화면으로(우리 앱 전용 화면, 협업자 화면 안 건드림).
- 단점: 커뮤니티(누구나) 옆에 회원 전용 유료 도구가 섞임 · 홈과 연구소 역할이 겹침.

### 어느 안이든 공통
- **댕생활 탭: 성장 탭을 없애고 오늘로 합침** → 오늘 · 이벤트 · 동네 · 안내 (4개)
- **우리 아이(`/my-pet`)**: 홈(추천안) 또는 마이 소속 — 마이 메뉴 "건강 기록"은 유지
- 반려견 등록은 마이 한 곳으로 모으고, 다른 화면은 버튼만

## 5. 앱 틀(우리 코드)에서 고쳐야 할 것 — 협업자 코드 안 건드림

| # | 문제 | 해결 |
|---|---|---|
| 1 | 케어톡 서랍이 화면 주소 `?q=` 를 읽어 **질문 자동 전송** | 서랍에서는 `?q=` 무시, `/chat?q=` 링크는 서랍 첫 질문으로 넘김 |
| 2 | 서랍 안 링크를 눌러도 서랍이 안 닫힘 | 서랍 안 링크 클릭 시 닫기 |
| 3 | "챗봇에 문의" 상품 이름 사라짐 | 서랍에 상품 맥락 전달 |
| 4 | 탭바(z-2150)가 검색 · 모바일 메뉴 · 국가 창 · 설치 안내 · 펫렌즈 창 · 댕자랑 프로필/신고/공유 창 **위에 그려짐** | 창이 열리면 탭바 숨김 (또는 탭바 z를 낮춤) |
| 5 | 댕자랑 토스트 · 착용 미리보기 알림이 **탭바에 가려짐** | 앱 모드에서 아래 여백을 탭바 높이만큼 |
| 6 | `/app/` 이 탭 첫 화면이 아님 | 홈 탭 경로 정리 |
| 7 | 네이티브 앱에서 댕생활 · 댕자랑 · 쇼핑 · 장바구니 · 상품이 **외부 브라우저로 나감** | 출시 때 번들 경로 추가 (협업자와 협의) |
| 8 | 시안 홈(ClassicHome)이 로그인과 연결 안 됨 | 실제 로그인 상태 + 출근도장 서버 연결 |

## 6. 협업자 코드 문제 (보고만, 수정은 협의 후)
1. `?profile=required` ↔ `?petProfile=required` 불일치 → 반려견 등록 폼이 안 열림 (댕생활 AI 추천 · 우리 아이 등록 버튼)
2. 이메일 회원 `authProvider` 미저장 → 비밀번호 변경 못 함
3. 찜이 로그인 · 로그아웃 때 지워짐
4. 출근도장 실패 시 "이미 찍혀 있어요" 오표시
5. 댕자랑 "자유 주제로 올리기" 무반응 · 내 글 신고 무반응 · 네트워크 오류 영문 노출
6. FAQ가 없는 주문 취소 기능을 안내
7. 탈퇴 · 비밀번호 변경 완료 안내 안 뜸 · 로그인 `?returnTo=` 무시
8. 펫렌즈 창: 저장 실패 문구 안 보임 · 분석 중 닫힘 경고 없음 · 기록 결과에 코인 사용 줄
9. 로그인 판단 두 군데 · 로그아웃 시 일부 값 남음 · 마이 진입 시 인증 메일 자동 발송
10. 쓰이지 않는 옛 부품(펫렌즈 `Petlens*`, 마이 부품 4개, 옛 로그인 폼)

## 7. 정해야 할 것
1. **연구소 위치** — 추천안(홈) / 유지안(댕다방)
2. **댕생활 탭** — 성장 → 오늘로 합쳐 4개 탭
3. **비회원 화면** — 연구소 · 우리 아이에 예시 결과 미리보기 넣을지
4. 탭바 위 창 처리 — 창 열리면 탭바 숨김으로 갈지
