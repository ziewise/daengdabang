# 03. 댕다방 연구소 (`/pet-lens` · `/petlens` · 펫렌즈 창) — 기능 전수 분석

> 로컬 분석 문서 (배포 X). 협업자 코드는 읽기만 했다. `/petlens` 는 `/pet-lens` 와 같은 화면이고, 모든 링크는 `/pet-lens` 로 간다.
> 같은 기능이 **화면(`/pet-lens`)** 과 **상단바 펫렌즈 창(모달)** 두 곳에서 열리며 부품을 같이 쓴다.

## 0. 먼저 알아야 할 문제
1. **연구소는 두 개의 서로 다른 서비스** — ① 사진 분석(펫렌즈, **무료**) ② 행동·소리·건강 신호 분석(영상, **1회 10코인**)
2. **펫렌즈 창(z-120)이 앱 탭바(z-2150) 아래에 깔림** → 창의 아래쪽 버튼이 탭바에 가려짐 (앱에선 상단바 자체가 쇼핑 탭에만 있어 창을 여는 곳도 쇼핑 탭뿐)
3. 사진 분석에서 입력한 이름·나이·크기·모질·활동량·관심 포인트는 **서버에 보내지도 저장하지도 않음**(사진만 분석)
4. 창에서 사진 분석 후 **기록 저장 실패 문구가 보이지 않음**
5. 영상 분석 중 창 바깥을 누르거나 Esc → **경고 없이 닫히며 진행이 끊김**(코인은 이미 예약됐을 수 있음)
6. 분석 기록에서 예전 결과를 열어도 "{n}C 사용 · 현재 {b}C"가 떠서 **새로 차감된 것처럼 보임**
7. `#observation` 이 붙은 링크는 모드만 바꾸고 그 위치로 스크롤되지 않음(해당 id 없음)
8. `?profile=` 은 창에선 무시, 화면에선 없는 아이면 조용히 첫째로 바뀜
9. 사진 분석 요청(`/api/v1/analyze-pet`)은 회원 전용인데 **토큰 없이** 보냄
10. 앱(네이티브)에서는 결과의 상품 카드 · 영양식 비교 · 네이버지도 링크가 **외부 브라우저로 나감**
11. 영어는 창의 메뉴와 탭만 지원
12. 쓰이지 않는 옛 부품(`Petlens*` 소문자 10개, 동기 분석 · 대기열 함수) 남아 있음

## 2. 로그인 전
- 화면 · 창 모두 자물쇠 안내: **"로그인 후 이용할 수 있어요"**
  - 사진 모드: "펫렌즈는 회원의 반려견 프로필을 기준으로 외형·체형·털 상태와 케어 포인트를 정리하는 회원 전용 기능입니다."
  - 관찰 모드: "댕다방 연구소 · 신규서비스" 제목 + "…카메라·마이크 신호를 개별 분석하는 회원 전용 서비스입니다."
  - **회원가입하고 시작하기** `/auth/signup?redirect=…` · **기존 회원 로그인** `/auth/login?redirect=…`
  - 돌아올 주소: 메일 링크면 그 결과 / 관찰 모드면 `/pet-lens?mode=observation` / 아니면 `/pet-lens` (창은 항상 `/pet-lens`)
- 회원 정보 확인 전: "회원 정보를 확인하고 있어요"
- **즉 비회원은 연구소에서 볼 수 있는 내용이 안내 한 장뿐**

## 3. 로그인 후 — 아이 상태별
| 상태 | 화면 |
|---|---|
| A. 서버에 저장된 아이 없음 | 발바닥 "반려견 프로필을 먼저 등록해 주세요" → **마이페이지에서 등록·확인하기** `/mypage?petProfile=required#pet-profiles` |
| B. 견종 미확인 | "등록 견종을 먼저 확인해 주세요" ("사진으로 견종을 다시 추측하지 않아요…") → 같은 버튼 |
| C. 준비 완료(서버 번호 + 견종) | 전체 화면 (§4 · §5) |
- 아이가 2마리 이상이면 **"분석할 반려견"** 선택 (준비 안 된 아이는 선택 불가 "견종 확인 필요") · 바꾸면 사진·결과 초기화, 관찰 모드는 지갑·기록 다시 불러옴

## 4. 사진 분석 (펫렌즈, 무료)
- **머리:** 화면 "펫렌즈 케어 · 펫렌즈" / 창 "우리 아이 분석하기"
- **모드 탭:** "사진·프로필 분석" · "댕다방 연구소 행동·소리(신규서비스)" (주소 안 바뀜)
- **입력:** 사진 4칸(정면 얼굴·가슴 / 왼쪽 옆선·다리 / 오른쪽 반대 옆선 / 뒷면 등선·꼬리, 모바일은 카메라 바로 열림) · 이름 · 나이 · 크기 · 모질 · 활동량 · 관심 포인트(눈 보호 · 피부/발바닥 · 체중 · 산책 안전 · 놀이/분리불안)
- **버튼:** 화면 "추천 받기" / 창 "분석하기" (창은 "보통 20~30초" 안내)
- **흐름:** 사진 1장이면 그대로, 2장 이상이면 한 장으로 합침 → `POST /api/v1/analyze-pet` → 회원이 확인한 견종으로 고정 → 결과 → 아이 프로필에 사진·결과 저장 `PUT /api/v1/pet-profiles/{id}`
- **오류 문구:** "정면 사진부터 촬영해 주세요." · "마이페이지에서 실제 견종을 먼저 확인해 주세요." · "현재 로컬 사진 분석이 잠시 지연되고 있어요…" 등
- **결과:**
  - 칩: 회원 견종 확인 / 근거 충분 / 후보 비교 필요 / 사진 보완 필요 · 사진 상태 · "{n}개 방향 확인"
  - 사진에서 확인한 특징 · 회원이 확인한 등록 견종 · 가까운 견종 후보("등록 견종을 자동으로 바꾸지 않아요") · 보호자 확인 · 다음 촬영 보완점 · 지금 도움이 되는 케어 · 상품 고른 기준
  - **내 아이 기록에서 결과 보기** → `/my-pet/#health-report`
  - 추천 상품 카드(상세 · 찜) / 없으면 "견종과 체형을 확인하면 상품 추천을 이어갈게요."
  - 창에서는 "다시 분석" 버튼

## 5. 행동·소리·건강 신호 분석 (영상, 10코인)
### 처음 화면
- 머리: 연구소 심볼 + "댕다방 연구소 행동·소리·건강 신호 분석 · 신규서비스"
- 들어오면 3가지 확인: 분석 연결 상태 · **코인 지갑** · 최근 분석 기록 8개
- 안내 카드: "권장 15초 동안 대상 강아지만 구분해 관찰해요" · 15초 권장 / 5~20초 / 최대 12MB · 연결 상태(연결됨 / 확인 중 / 점검 중 "다시 확인")
- **지갑 상자:** "1회 10C" · 잔액 · 분석 가능 n회 · 부족하면 "적립금 1,000P를 10C로 바꿀 수 있어요" → **전환하러 가기** `/mypage#daenglab-wallet`
- **최근 분석 기록:** 긴급도(즉시 병원 연락 / 오늘 병원 문의 / 평소와 비교 관찰 / 판단 어려움) · 날짜 · 요약 → 누르면 결과 열림
- **응급 안내(항상):** "이럴 때는 촬영보다 병원 연락이 먼저예요"

### 촬영
| 단계 | 버튼 |
|---|---|
| 처음 | **카메라·마이크 연결** · **촬영한 영상 선택**(WebM/MP4/MOV) |
| 연결 중 | 연결 취소 |
| 미리보기 | **15초 관찰 시작** · 연결 끊기 |
| 녹화 중 | 촬영 중단 |
| 녹화 완료 | **이 영상 분석하기 · 10C** (혼자면 "혼자 보이면 콕 없이 분석하기") · 다시 촬영 · 영상 선택 |
- 동의 없이 연결/선택하면 → **동의 확인 창**
- 연결·녹화는 **전체 화면 검은 촬영 창**(z-2600, 탭바 위): "{이름} 촬영 준비/관찰 녹화 중" · 카메라 전환 · 닫기/중단 · 남은 초 · **기기 안 1차 스캔**(밝기·흔들림·소리) · 영상을 콕 눌러 **분석할 아이 지정**
- 아래: 카메라·마이크 선택 · 전후면 전환
- 오른쪽 입력: **촬영 당시 상황**(잘 모르겠어요 / 혼자 / 낯선 사람·소리 / 놀이 / 식사 / 산책 / 쉬는 중 / 그 밖) · **대상견 선택**(왼쪽·가운데·오른쪽 몸통, "한 마리만 보여요") · 메모 300자 · **동의 체크** · 진단 아님 안내

### 분석 흐름
1. `POST /api/v1/pet-lens/observation-jobs` (영상 · 대상 사진 · 아이 · 상황 · 동의) → 10C 예약
2. 바로 완료 → 결과 / 오래 걸림 → 3초마다 확인 + **"분석 완료 알림" 창**: "예, 이메일 알림" / "아니오, 분석 취소(코인 환급)"
3. 실패·아이 미검출·대상 구분 실패·결과 0건 → **자동 환급** "분석 비용 전액 환급 완료"

### 결과
- "새로 관찰" 버튼 · 코인 줄
- 긴급(즉시/오늘)이면 맨 위 **긴급 안내** + "네이버지도에서 가까운 24시 동물병원 찾기"
- 펫렌즈 전체 총평 · 분석 대상 분리 · **짖음·발성 맥락 번역 후보**("사람 문장 번역 아님") · **시간별 행동·소리·건강 관찰 그래프** 4묶음 · (대상 불명이면 "분석 보류 리포트")
- 조건 맞으면 **우리 아이 영양식 비교 제안** → 자사 상품 `/product/...` / `/category/food`
- 원본 삭제 안내 · 촬영 품질 · 관찰 근거 · 행동 패턴 후보 · 확인할 신호 · 다시 촬영 팁
- **결과 이메일로 받기**(가입 메일 또는 다른 메일 인증 후 1회 발송)
- **보호자 답변 메모**(예/아니오/모르겠어요 + 메모, 추가 0C)

## 6. 주소 붙임값
- `?mode=observation` · `#observation` → 관찰 모드
- `?profile={id}` → 그 아이 (화면만)
- `?observation={요청번호}` (메일 링크) → 비회원: 로그인 안내 / 회원: "분석 기록 확인 중" → 완료면 결과, 진행 중이면 자동 대기, 다른 계정이면 "다른 계정으로 다시 로그인"

## 7. 펫렌즈 창(상단바)
- 메뉴: "우리 아이를 어떻게 분석할까요?" → **댕댕이 사진 분석** / **행동·소리·건강 신호 분석(신규서비스)**
- 닫힘: 바깥 · × · Esc · 페이지 이동 / 관찰 화면에만 "뒤로", 사진 화면엔 없음

## 8. 코인
- 코인 쓰는 곳은 **행동·소리 분석 1회 10C 하나뿐**
- 코인 받는 곳: 가입 축하(이메일 인증 20C) · 구매 확정 적립 → 전환(1,000P→10C, 마이페이지) · **매일 출근도장(기본 2C)** · **오늘 돌봄 챌린지** · 실패 환급
- 지갑 잔액이 바뀌면 화면끼리 실시간 공유(`ddb:daenglab-wallet`)

## 9. 서버 주소
사진 분석 `POST /analyze-pet`(인증 없음) · 프로필 저장 · 연결 상태 `GET /pet-lens/capture-config` · 지갑 · 기록 `GET /pet-lens/observations` · 분석 요청/확인 `observation-jobs` · 알림 선택 `delivery-choice` · 보호자 답변 `refine` · 결과 메일 · 메일 인증 · 분석 이벤트

## 10. 분석 이벤트
`petlens_opened` · `petlens_started` · `petlens_completed` · `petlens_failed` · `petlens_target_anchor_selected` (기록 열기 · 메일 · 메모 · 동의 · 카메라 권한은 이벤트 없음)

## 12. 확인이 필요한 질문
1. 연구소 화면에서 탭바를 계속 보여 줄지(분석 · 결과 중 숨김?)
2. 앱에서 펫렌즈 창을 쓸지(쓴다면 탭바 위로) — 앱에선 탭 화면(`/pet-lens`)만으로 충분해 보임
3. 사진 화면 "뒤로" 버튼 추가
4. `#observation` 스크롤 위치 · `?profile=` 없는 아이 안내
5. 앱(네이티브)에서 결과의 상품 링크가 외부로 나가는 흐름
6. 사진 분석 요청에 인증을 붙일지
7. 쓰이지 않는 옛 부품 정리
