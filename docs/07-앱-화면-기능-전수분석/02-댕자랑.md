# 02. 댕자랑 (`/daeng-showcase/`) — 기능 전수 분석

> 로컬 분석 문서 (배포 X). 협업자 코드를 읽기만 하고 정리했다. 경로는 `D:\Daengdabang\Daengdabang_Shop\` 기준.

## 0. 범위 파일
- `app/daeng-showcase/page.tsx` — 메타데이터 + `<DaengShowcaseClient />` (title "오늘의 댕자랑 | 반려견 일상 커뮤니티 | 댕다방", canonical `/daeng-showcase/`)
- `components/daeng-showcase/DaengShowcaseClient.tsx` — 히어로 · 주제 카드 · 작성/비회원 안내 · 피드 탭 · 그리드 · 페이지 · 모달 · 토스트
- `ShowcaseTopicCard.tsx`(오늘의 댕주제) · `ShowcaseComposer.tsx`(회원 업로드) · `ShowcaseCard.tsx`(게시물 + 신고 모달) · `ShowcaseAuthorProfileModal.tsx` · `ShowcaseShareModal.tsx`
- `lib/daeng-showcase.ts`(API · 정규화 · 이미지 검증) · `lib/daeng-showcase-share.ts`(딥링크 · 로그인 복귀 · UTM)

**구현되지 않은 것:** 댓글, 게시물 수정, 알림, 무한 스크롤, 정렬, 검색, 추가 필터(전체/팔로잉만), 업로드 전 이미지 압축·자르기, 업로드 취소, 보상(코인·XP·포인트 없음).

## 1. 로그인 판단
- `authenticated = Boolean(user && user.apiAccessToken)` — 토큰 없는 로컬 사용자도 **비회원**으로 취급.
- 하이드레이션 전: 히어로는 비회원 버튼("회원가입하고 시작")이 잠깐 보임 · 작성 칸 자리 표시 · 피드는 하이드레이션 후 불러옴. 주제는 먼저 토큰 없이 한 번, 토큰 생기면 다시 한 번.
- `requireAuth()` → `/auth/login?redirect=<현재 주소, post·topic·author·utm 만 유지>`.
- ID 형식: post `^dsp_…{20,32}$` · topic `^dst_…{12,40}$` · author `^dsa_…{20,32}$`.

## 2. 비회원 화면 (위→아래)
1. **히어로** — "DAENGDABANG SHOWCASE" · "지금 참여 가능" / H1 "누구나 보고, 회원이면 바로 올리는 / 오늘의 댕자랑" / 설명(공개 피드는 로그인 없이, 사진 올리기·팔로우·뼈다귀 응원은 회원).
   - "회원가입하고 시작" → `/auth/signup?redirect=…` · "최신 댕자랑 보기" → `#showcase-feed` 로 스크롤
   - 옆 안내 "OPEN COMMUNITY · 가볍게 나누고 안전하게 지켜요" 3줄
2. **오늘의 댕주제** (`#showcase-topic`) — "이 주제로 올리기" → 회원가입
3. **작성 칸 자리** — "JOIN & SHARE · 회원가입하면 바로 올릴 수 있어요" + 회원가입 · 로그인
4. **피드** — "TODAY'S SHOWCASE · 오늘 올라온 댕자랑", 탭 전체/팔로잉(비회원은 팔로잉 → 로그인), 카드 1·2·3열, 9개씩, 아래 페이지 버튼
5. **카드에서 비회원** — 프로필 보기 · 공유 · 더보기는 가능 / 팔로우 · 응원 · 신고 → 로그인 / 삭제 없음

## 3. 회원 화면
- 히어로 버튼 → "사진 올리기"(작성 칸으로 스크롤)
- **작성 칸** ("SHARE TODAY · 오늘의 한 장 올리기 · 회원 공개 게시")
  - 사진 1장(JPG·PNG·WebP, 8MB 이하, 미리보기 · 지우기 · 다른 사진 선택) — 형식/빈 파일/용량 오류 문구
  - 오늘의 이야기(2~500자, 글자 수 표시) · 피드에 보일 이름(2~30자, 회원 이름 자동 — 이메일·주소 형태면 "댕다방 친구")
  - 함께 나온 반려견(선택 — 서버 등록된 아이만, 없으면 "표시하지 않기"만. **반려견 등록 링크 없음**)
  - 오늘의 댕주제 참여(진행 중 주제 있을 때, 기본 체크)
  - 필수 동의(공개 게시 · 개인정보 주의, 개인정보처리방침 링크) · 선택 동의(공식 인스타·스레드·블로그 소개, 기본 해제)
  - "오늘의 댕자랑 공개하기" → 업로드 진행률 표시 → 성공: 폼 초기화(이름 유지) · "댕자랑을 공개했어요…" · 주소 `?post=…` · 맨 앞에 강조 · 스크롤 / 실패: 서버 문구 등 (401 이어도 로그인으로 보내지 않음)
- 탭 팔로잉 사용 가능
- **카드 상태** — 내 글: "나" 배지 · 팔로우 없음 · 삭제(가능할 때) 또는 신고(눌러도 아무 일 없음) · 응원 가능 / 남의 글: 팔로우 ↔ 팔로잉 · 응원 n(토글) · 신고 → 모달

## 4. 오늘의 댕주제 카드
| 상태 | 보이는 것 |
|---|---|
| 불러오는 중 | 자리 표시 |
| 오류 | "오늘의 댕주제를 불러오지 못했어요." + 주제 다시 불러오기 |
| 주제 없음 | "새 주제를 준비하고 있어요…" + "자유 주제로 올리기" — **버그: 눌러도 아무 일 없음** |
| 진행 중 | 기간(M월 D일–M월 D일 · KST) · "참여 중" · "오늘의 댕주제 · {제목}" · 안내 + "이 주제로 올리기"(비회원→가입 / 회원→작성 칸) · "주제 공유카드" |
| 지난 주제 | "지난 주제" · 참여 버튼 숨김 · 공유카드 유지 |
| 운영자 선정 대표작 | "FEATURED SHOWCASE" 이미지 · 설명 + "대표 댕자랑 정확히 보기" |
| `?topic=` 딥링크 | 강조 테두리 + 스크롤 |

## 5. 피드 상태
- 불러오는 중: 카드 6개 자리 표시 / 오류: 문구(팔로잉 401 → "팔로잉 피드는 로그인 후 볼 수 있어요.", 네트워크 오류는 **영문 원문 노출**) + 다시 불러오기 (+팔로잉이면 로그인)
- 비어 있음(전체): "첫 번째 댕자랑의 주인공이 되어 주세요" / (팔로잉): "팔로우한 친구의 첫 소식을 기다려요" + 전체 피드 보기
- 페이지: 이전 · {n}페이지 · 다음 (무한 스크롤 없음)

## 6. 카드
- 머리(작성자 · 팔로워 수 · 날짜) → 프로필 모달 (`?author=`)
- 사진(정사각, 지연 로딩, **실패 시 대체 이미지 없음**) · 반려견/주제 표시(주제는 눌러지지 않음) · 글 3줄 + 더보기/접기
- 아래: 응원 n · 공유 · 삭제/신고
- 팔로우 · 응원: 먼저 화면 반영 → 서버 결과 반영, 실패 시 되돌림 · 401 → 로그인 · 그 외 오류 토스트
- 삭제: 확인창 "이 댕자랑을 삭제할까요? 삭제하면 되돌릴 수 없습니다." → "게시물을 삭제했어요."
- **신고 모달**: 이유(광고·도배 / 개인정보 노출 / 괴롭힘·혐오 표현 / 저작권 침해 / 기타) · 상세(300자) · "신고 접수" → "신고를 접수했어요. 운영자가 확인하겠습니다." 또는 "이미 접수된 게시물이에요." (Esc 닫기 없음)

## 7. 작성자 프로필 모달
- 카드 머리 또는 `?author=` 로 열림 · Esc/바깥 닫기
- 게시물 수 · 팔로워 · 받은 응원 · 팔로우(남) / "내 프로필"(나) · 최근 댕자랑 최대 12개 썸네일(누르면 그 글로) · 글 없으면 빈 칸(안내 문구 없음)
- 여기서 팔로우하면 분석 이벤트가 안 남음(카드에서만 남음)

## 8. 공유 모달 ("SAFE SHARE CARD · 댕자랑 공유카드")
- 미리보기(글: 사진·글 / 주제: 발바닥·질문) · "공유 창 열기"(기기 공유) · "링크 복사"(막히면 주소 직접 복사)
- 주소: `https://www.daengdabang.com/daeng-showcase/?post=…&utm_source=member_share&utm_medium=referral&utm_campaign=daeng_showcase&utm_content=post_<id>` (주제는 `topic_<id>`)
- 로그인 필요 없음 · 분석 이벤트 없음

|---|---|---|---|---|
| 회원가입하고 시작 | 비회원 | `/auth/signup?redirect=…` | – | 가입 |

| 최신 댕자랑 보기 | 모두 | 피드 스크롤 | – | – |
| 이 주제로 올리기 | 진행 중 주제 | 비회원 가입 / 회원 작성 칸 | – | – |
| 자유 주제로 올리기 | 주제 없음 | (동작 없음) | – | **버그** |
| 주제 공유카드 | 주제 있음 | 공유 모달 | 불필요 | – |
| 대표 댕자랑 정확히 보기 | 대표작 | `?post&topic` + 강조 | 불필요 | – |

## 10. 데이터 · 분석
- 읽기(비로그인 가능): 피드 · 글 하나 · 작성자 · 현재 주제(`/topic`) · 특정 주제(`/topics/{id}`) · 이미지 `/api/v1/showcase/posts/{id}/image`
- 쓰기(토큰 필요): 게시(동의 버전 `ddb-showcase-public-v1`, 공식 채널 `ddb-showcase-official-channels-v1`) · 팔로우 · 응원 · 신고 · 삭제
- 분석 이벤트: `page_view` · `showcase_first_post_completed` · `showcase_follow_completed`(카드만) · `showcase_bone_completed` — 공유 · 탭 · 신고 · 삭제는 기록 없음

## 11. 화면 아래 고정 요소 (앱 탭바와 충돌)
- 토스트: `bottom 20px · z-2050` → **탭바(z-2150, 아래 76px+) 밑에 가려 안 보임**
- 프로필 모달 z-2090 · 신고 모달 z-2100 → **탭바보다 아래, 신고 버튼 가려질 수 있음 · 탭바가 위에서 눌림**
- 공유 모달 z-2150 = 탭바와 같음 → 탭바가 위에 그려짐
- 상단 여백: 스크롤 기준 112px ≈ 상단바+버튼 줄 106px (빠듯)
- 웹 화면에서는 챗봇 버튼(z-2200) · 산책 강아지(z-2080~2211)도 겹침 — 앱 틀에서는 이미 숨김

## 12. 발견한 문제
- "자유 주제로 올리기" 동작 없음 · 내 글 "신고" 눌러도 무반응 · 팔로잉→전체 전환 시 페이지 위치가 안 초기화됨(다른 피드 커서로 불러옴) · 네트워크 오류 영문 노출 · 이미지 실패 대체 없음 · 신고·프로필 모달 포커스/ Esc 처리 부족 · 업로드 401 은 로그인으로 안 보냄 · 하이드레이션 전 회원에게 비회원 버튼이 잠깐 보임

## 13. 확인이 필요한 질문
1. 앱 틀에서 토스트를 탭바 위로 올릴지, 모달이 열리면 탭바를 숨길지
2. "자유 주제로 올리기"의 의도(회원 → 작성 칸, 비회원 → 가입?)
3. 내 글에 응원이 서버에서 막히는지
4. 프로필에서 팔로우도 분석 이벤트를 남길지 · 공유도 기록할지
5. 업로드 401 도 로그인으로 보낼지
6. 반려견이 없는 회원에게 작성 칸에서 등록 링크를 줄지
7. 첫 게시 · 팔로우 · 응원에 서버 보상(코인·XP)이 있는지 (화면엔 없음)
