# 04. 마이 (`/mypage` · 하위 화면 · `/my-pet` · 고객센터) — 기능 전수 분석

> 로컬 분석 문서 (배포 X). 협업자 코드를 읽기만 하고 정리했다. 마이페이지 화면은 모두 브라우저에서 그려지며 제목은 "댕다방"(우리 아이만 "우리 아이 | 댕다방").

## 0. 먼저 알아야 할 문제
1. **이메일 회원이 비밀번호를 바꿀 수 없음** — 이메일 로그인 · 가입 때 가입 방식(`authProvider`)을 저장하지 않아, 정보 수정 화면이 "비밀번호는 구글에서 관리합니다."로 잘못 보여 줌(소셜 로그인만 값이 들어감)
2. **같은 뜻에 두 가지 주소** — 마이페이지는 `?petProfile=required` 만 읽는데, 우리 아이 "반려견 등록하기"와 매일 댕생활 "AI 추천"은 `?profile=required` → **등록 폼이 자동으로 안 열림**
3. 탈퇴 뒤 `/?account=withdrawn`, 비밀번호 변경 뒤 `/auth/login/?reason=password_changed` 를 읽는 곳이 없어 **완료 안내가 안 뜸**
4. **찜은 브라우저에만 저장, 로그인 · 로그아웃 때 모두 지워짐** — 비회원이 찜한 것도 로그인하면 사라짐(서버 저장 없음)
5. 마이페이지 · 정보 수정 · 결제수단 · 배송지 · 탈퇴는 로딩 판단 없이 그려서 **회원에게도 "로그인이 필요합니다."가 잠깐 보임** (`#pet-profiles` 자리로 바로 못 갈 수 있음)
6. 자주 묻는 질문이 없는 기능을 안내 — "마이페이지 > 주문 내역에서 취소"라고 하지만 **주문 취소 버튼 없음**, "주문 내역 보기 · 배송 조회하기"가 `/mypage` 로 감
7. 조건이 맞으면 **마이페이지에 들어오기만 해도 인증 메일이 자동 발송**됨(가입 혜택 대기 상태)
8. 로그아웃은 브라우저에서만(서버 로그아웃 없음), 일부 저장값은 안 지워짐
9. 쓰이지 않는 마이페이지 부품 4개 · 옛 로그인 화면은 연결 없음
10. 금액은 통화 설정(USD)과 상관없이 항상 "원", 마이페이지 문구는 한국어만
11. 반려견 프로필 **삭제 없음**, 관심 고민(concerns) 수정 불가(등록 시 "일상 케어" 고정)

## 2. 로그인 전
| 화면 | 보이는 것 | 버튼 |
|---|---|---|
| `/mypage` | "로그인이 필요합니다." | 로그인 `/auth/login` · 회원가입 `/auth/signup` |
| 정보 수정 · 결제수단 · 배송지 · 탈퇴 · 추천 설정 | 자물쇠 "로그인이 필요합니다." "회원 정보는 본인 확인 후에만 볼 수 있습니다." | 로그인(돌아올 주소 포함) · 마이페이지로 |
| 주문 내역 | "주문과 배송정보는 본인 확인 후에만 볼 수 있습니다." | 로그인 후 주문 보기 |
| 우리 아이 | "우리 아이 기록은 로그인 후 볼 수 있어요" | 로그인하기 `/auth/login/?redirect=%2Fmy-pet` |
| FAQ · 공지 · 문의 · 교환반품 · 약관 등 | 누구나 같음 | §6 |

**로그인 화면:** 홈으로 `/main` · 이메일/비밀번호 → `POST /api/v1/auth/login` → `GET /auth/me` → `GET /pet-profiles` → 이동(기본 `/mypage`, 연구소에서 왔는데 프로필 미완성이면 `/mypage?petProfile=required#pet-profiles`) · 비밀번호 찾기 `/forgot-password` · 네이버/카카오/구글 → 소셜 시작 → `/auth/social-callback` · 회원가입 · (결제에서 왔으면) 비회원 주문서 미리보기

## 3. 로그인 후 — 마이페이지 대시보드
- **머리:** "마이페이지" · "{이름}님" · 계정 표시(카카오/네이버/구글 간편가입 회원 · 이메일 · "댕다방 회원")
- **왼쪽 메뉴** (모바일은 위쪽 2열):
  | 묶음 | 메뉴 | 주소 |
  |---|---|---|
  | 우리 아이 AI | 건강 기록 · AI 분석 · 매일댕생활·출근도장 | `/my-pet` · `/pet-lens` · `/treasure-mine/` |
  | 쇼핑 정보 | 대시보드 · 주문 내역 | `/mypage` · `/mypage/orders` |
  | MY 정보 | 개인정보 확인/수정 · 추천 데이터 관리(설정 시) · 결제수단 관리 · 배송지 관리 · 회원 탈퇴 | `/mypage/profile` · `/recommendations` · `/payments` · `/address` · `/withdrawal` |
  | – | 로그아웃 | 확인창 → 로그아웃 → `/main` |
- **지갑** (`#daenglab-wallet`) "댕다방 연구소 지갑 · 적립금"
  - 적립금 P · 코인 C · 분석 가능 n회 · 새로고침(`GET /api/v1/daenglab/wallet`)
  - 차감 예정 안내(취소·환불 회수)
  - **적립금 → 코인 전환**(1,000P → 10C 단위, 되돌릴 수 없음) `POST /api/v1/daenglab/wallet/convert`
  - 상품별 코인 지급 기준(1/3/6/10/15/20C) · 최근 내역 5건(가입 축하 코인 · 구매확정 적립 · 취소 회수 · 적립금 전환 · 행동·소리 분석 · 분석 실패 환급 · **매일 출근도장 · 오늘 돌봄 챌린지**)
  - **"이메일 인증하고 20C 받기"** (가입 혜택 대기 중일 때만) — 인증번호 받기 → 6자리 확인 → 가입 축하 코인 지급 (이 화면이 앱 안 유일한 이메일 변경 경로)
- **반려견 프로필** (`#pet-profiles`)
  - 없음: "먼저 우리 아이 이름과 실제 견종을 등록해 주세요…" + 첫 강아지 등록하기
  - 카드마다: 사진(서버 확인된 것만) · 이름 · 견종 · 크기·나이·털 · 체중·성별 · 털색·활동량 · "착용 상품 자동 피팅 가능"/"사진을 올리면 자동 피팅이 켜집니다" · 고민 최대 4개 · 정보 수정
  - 아래: 펫렌즈 사진 분석 열기(준비된 아이 있을 때) / 안내(준비 안 됨) · 자동 피팅 상품 보기(사진 확인 시)
  - **등록 폼:** 이름 · 실제 견종(필수) · 앞·뒤·좌·우 사진 4장 · 크기 · 나이 · 체중 · 성별 · 모질 · 털 색 · 활동량 · 선택 개인정보 동의 → `POST /api/v1/pet-profiles` → "…프로필을 등록했습니다." + 펫렌즈 사진 분석 시작하기 · 강아지 추가 등록
  - **수정 폼:** 이름은 수정 불가 · 견종 · 사진 · 크기 · 나이 · 체중(예상 범위) · 성별 · 모질 · 털 색 · 활동량 → `PUT /api/v1/pet-profiles/{id}`
- **최근 결제**(이 브라우저에서 결제한 것만) · 전체 주문 보기
- **바로 입혀볼 상품**(사진 확인 시) · 산책용품 보기 `/category/outdoor`
- **찜한 상품**(브라우저 저장) · 상품 더보기 `/products`

## 4. 하위 화면
- **주문 내역** `/mypage/orders` — `GET /api/v1/payments/toss/orders?limit=20&offset=N` (결제완료 · 테스트 결제완료만) · 검색(불러온 것 안에서) · 카드(날짜 · 주문번호 · 상태 · 주문 상세보기 · 배송 박스 · 상품 2개 + 외 n개 · 총 결제금액 · **배송 조회/배송 문의 · 교환·반품 안내**) · 주문 더 보기
  - **상세** `?orderId=` — 상태 · 상품 · 받는 사람 정보(배송 요청사항 · 공동현관 · 택배사 · 송장번호) · 결제 정보(결제수단 · 상품금액 · 배송비 · 총액) · 테스트 주문 안내
  - **취소 · 반품 버튼 없음**
- **개인정보 확인/수정** — 이름 변경(`PATCH /api/v1/auth/me`) · 이메일·계정 변경 문의 → `/inquiry?category=other#inquiry-form` · 비밀번호 변경(이메일 회원만 — §0.1 버그) → 현재/새 비밀번호 → `POST /api/v1/auth/change-password` → 모든 세션 종료 · 로그인 화면
- **결제수단 관리** — 안내만(저장된 결제수단 없음, 결제 때 토스에서 선택) · 장바구니에서 결제하기 · 주문 내역 확인
- **배송지 관리** — 최대 10개 · 목록/수정/기본으로/삭제(확인) · 새 배송지(이름 · 받는 분 · 연락처 · 우편번호 · 주소 · 상세 · 기본 설정, **우편번호 검색 없음**) · `GET/POST/PUT/DELETE /api/v1/customer-addresses` · 기본 `POST …/{id}/default`
- **추천 데이터 관리** — 맞춤 추천 전체 · 반려견 프로필 · 펫렌즈 케어 신호 (각 즉시 저장) · 행동 데이터(준비 중) · 기본 추천 반려견 · 현재 사용 상태 · 원본 데이터 링크(프로필 수정 · 분석 기록 확인 · 분석 결과 삭제 요청 · 개인정보 처리 안내) · `GET/PUT /api/v1/recommendation-preferences` · 이벤트 `recommendation_preferences_updated`
- **회원 탈퇴** — 되돌릴 수 없음 안내 · 동의 체크 · 현재 비밀번호(이메일 회원) · "회원 탈퇴" 직접 입력 → `POST /api/v1/auth/withdraw` → 로그아웃 → `/?account=withdrawn`

## 5. 우리 아이 (`/my-pet`)
- 반려견 없음: "먼저 우리 아이를 등록해 주세요" + 반려견 등록하기(→ **잘못된 주소** §0.2)
- 있음: `?profile=` 로 고름(없으면 첫째) · 머리(사진 · "MY PET WEEKLY HISTORY" · "{이름}의 기록" · 견종 · 체중) · 아이 선택 · 요약 3칸(최근 주간 사진 · 주간 비교 기록 n개 · 관심 케어)
- **`#health-report` AI 주간 사진 변화 리포트** — `GET /api/v1/pet-profiles/{id}/photo-analyses?limit=8` · 이번 주 분석 · 이전 주와 비교 · 최근 4건 · 의료 진단 아님
- **새 주간 분석 시작** → 전체 화면 촬영 창(정면/왼쪽/오른쪽/뒷면 4장, 카메라 또는 사진 선택) → `POST …/photo-analyses` (업로드 진행률, 180초) → "이번 주 변화 기록이 쌓였어요!"
- **행동·소리 분석 열기** → `/pet-lens/?mode=observation#observation`

5. FAQ 주문 취소 문구를 고칠지, 주문 취소 기능을 만들지
6. 로그아웃 때 서버 토큰 폐기 · 옛 저장값 정리
7. 금액 통화 · 마이페이지 번역
8. 반려견 프로필 삭제 · 고민 수정 지원
9. 마이페이지 진입 시 인증 메일 자동 발송이 의도인지
10. 쓰이지 않는 부품 정리
