# 05. 케어톡 · 앱 홈 · 로그인/가입 · 쇼핑 — 기능 전수 분석

> 로컬 분석 문서 (배포 X). 협업자 코드는 읽기만 했다.

## 0. 먼저 알아야 할 문제
1. **케어톡 서랍이 숨어서 질문을 자동 전송** — 서랍은 한 번 열면 닫아도 안에 남아 있는데, 케어톡이 **지금 화면 주소의 `?q=` 를 읽음** → 검색 결과 `/products?q=하네스` 에서 서랍을 열거나, 서랍을 연 뒤 그 주소로 가면 "하네스"가 질문으로 저절로 보내짐. 또 `/chat?q=...` 링크는 서랍으로 바뀌면서 `q` 가 버려짐 **(우리 앱 틀에서 생긴 문제 — 고쳐야 함)**
2. 서랍 안 상품 카드 · 안내 링크를 누르면 **뒤 화면만 바뀌고 서랍은 그대로 열려 있음** (웹 채팅창은 스스로 닫힘)
3. 상품 상세 "챗봇에 문의"는 앱에서 서랍을 열지만 **상품 이름이 전달되지 않음**
4. `chat_opened` 는 서랍 첫 열림에만 1번
5. 대화 번호를 저장하지만 들어올 때마다 지워서 이어 보기가 안 됨 · 대화 내용은 새로고침하면 사라짐
6. 채팅 중 로그인이 만료돼도 "다시 시도"만 나오고 로그인 안내 없음
7. **앱(네이티브)에선 `/treasure-mine` · `/daeng-showcase` · `/`(쇼핑) · `/cart` · `/checkout` · `/product/*` 가 외부 브라우저로 나감** → 지금 앱 틀의 댕생활 · 댕다방 · 쇼핑 탭이 앱 밖으로 나가는 구조 (번들 경로 목록에 추가 필요)
8. `/app/` 은 탭 첫 화면이 아니라 "홈" 뒤로 버튼이 나옴 (홈 탭 = `/app/mockup-c/`)
9. 로그인 화면이 `?returnTo=` · `?reason=password_changed` 를 무시
10. 로그인 여부를 두 곳(`daengdabang_logged_in` / store)에서 따로 봄 → 상단바와 화면이 어긋날 수 있음
11. 탭바(z-2150)가 **검색 창(2000) · 모바일 메뉴(1500) · 국가·언어 창(1300) · 앱 설치 안내(1900) · 펫렌즈 창(120) · 댕자랑 알림(2050)** 위에 그려짐 · 착용 미리보기 알림(아래 96px)은 탭바와 겹침

## 1. 케어톡 (`/chat` · 웹 채팅창 · 앱 서랍)
### 로그인 전
- "CRAYON CARE NOTE · 댕다방 케어 톡 · 대화 N개" · 빈 화면 "우리 아이 이야기를 편하게 들려주세요"
- **질문은 비회원도 가능**(아이 정보 없이)
- 글씨체 전환 · 새 대화(메시지 있어야 눌림) · 닫기
- 사진 첨부 → "참고사진 첨부는 로그인이 필요해요." + 로그인하기 `/auth/login?redirect=%2Fchat`
- 제작 "로그인 후 실제 제작" 비활성 · 좋아요/아쉬워요 가능
### 로그인 후
- **"상담 아이" 선택** (첫째 기본, 바꾸면 새 대화)
- 사진 첨부 최대 2장(10MB, 종류: 대상/상품/배경/자세/조명/스타일)
- 새 대화 → "새 대화를 시작했어요."
### 답변 안에 나오는 것
| 요소 | 동작 |
|---|---|
| 함께 살펴볼 상품(최대 4) | `/product/{slug}` · 찜 |
| 확인한 출처 | 외부 링크 |
| 제작 요청 → 실제 제작 시작 | 이미지/영상 생성(회원) |
| **가까운 후보 보기**(동물병원 · 미용 · 호텔 · 데이케어) | 위치 → 근처 5곳 · 네이버지도 · 전화 |
| 안내 버튼 | 내부 이동 / 외부 / 이어 묻기 |
| 선택지 · "답이 없어요. 직접 적을게요" · 추가정보 한 번에 입력 | 이어 묻기 |
| 다시 확인하기 · 👍👎 | 재질문 · 피드백 |
| 멈추기 | 질문을 입력창으로 되돌림 |
- 진행 표시: 답변 준비 → 질문 살펴보기 → 자료 확인 → 검토, "N초 경과"
- 연결 실패: 잠시 후 재시도 / 바쁨 / 시간 초과 / 이전 대화 만료 등
### 세 가지 모양
| | 웹 `/chat` 화면 | 웹 채팅창(오른쪽 아래 떠 있는 버튼) | **앱 서랍(우리 틀)** |
|---|---|---|---|
| 아이 선택 | O | X(첫째) | O |
| 상품 문의 맥락 | X | O("상품 문의" 표시) | **X(전달 안 됨)** |
| `?q=` 자동 질문 | O | X | **O(버그)** |
| 링크 누르면 닫힘 | – | O | **X** |
- 웹 채팅창은 처음 화면 맨 위 · 스크롤 중 · 다른 창 열림 · 연구소 결과 중엔 숨음, 상품 구매바가 있으면 위로 올라감
- 앱 틀에선 떠 있는 버튼 대신 **상단바 케어톡 버튼 → 서랍**(92% 높이, 바깥·Esc·손잡이 끌기로 닫힘)
- 케어톡으로 가는 링크 위치: 상단바 연구소 메뉴 · 모바일 메뉴 · 앱 홈 · AI 케어 요약 "CareTalk 열기" · 시안 홈 · 빠른 메뉴 · 커뮤니티 · 브랜드 스토리 · 상품 상세 "챗봇에 문의"

## 2. 앱 홈
### `/app/` (협업자 앱 홈, MobileAppHome)
- 비회원: "회원으로 이어서 이용해 보세요" + 로그인
- 회원: "{이름}님과 댕생활" + **AI 케어 요약**
  - 아이 없음: "우리 아이부터 연결해 주세요" → 반려견 등록하기
  - 있음: 분석 연결 상태 · 아이 선택 · 카드 3개(사진 분석 / 주간 리포트 / 행동·소리) · CareTalk 열기
- 바로가기: 매일 댕생활 · 댕자랑 · 연구소 · 우리 아이 · AI 상담 · 마이페이지 · 쇼핑
- 앱 설치: 바로 설치 / iPhone 설치 안내 / 설치 방법 보기 · "홈 화면 앱으로 실행 중이에요"
### `/app/mockup-c/` (지금 홈 탭, ClassicHome 시안)
- **로그인과 연결 안 됨** — "로그인 전 / 로그인 후(예시)" 전환 + 예시 데이터
- "오늘 출근도장 찍기"는 화면만 바뀜(실제로는 `POST /daenglab/wallet/attendance/claim` 연결 필요)
- 링크: 로그인 · 카드(댕생활 · 댕자랑 · 연구소) · 우리 아이 · 케어톡 · 마이 · 쇼핑
### 앱 설치 관련
- 상단바 "앱 홈" 버튼(모바일, `/app*` 아닌 곳에서 항상) · 웹 홈 "댕다방을 앱처럼 바로 열기" · 모바일 메뉴 "댕다방 앱 설치"/"댕다방 앱 홈" · 설치 안내 창(iOS/Android/인앱 브라우저 경고, 앱 주소 복사)
### 네이티브 앱(Capacitor)에서 앱 안에 머무는 주소
`/app` `/auth` `/chat` `/legal` `/my-pet` `/mypage` `/offline` `/pet-lens` `/petlens` `/privacy` `/terms` — **그 밖은 외부 브라우저**(`/products` 는 실제 사이트로 이동)

## 3. 로그인 · 가입
- **로그인** `/auth/login` (상단바 · 탭바 없음): 홈으로 · 이메일/비밀번호 · 비밀번호 찾기 · 네이버/카카오/구글 · (결제에서 왔으면) 비회원 주문서 미리보기 · 회원가입
  - 로그인 뒤: 연구소에서 왔고 아이 준비 안 됐으면 마이페이지 등록 / 아니면 돌아갈 주소 / 기본 `/mypage`
- **가입** `/auth/signup`: "신규 가입 혜택 · 20C" · 약관 동의(필수 2 + 펫렌즈 선택) · **봇 확인(Turnstile)** · 소셜 가입 · 이메일 가입(이름 · 이메일 · 비밀번호 + 선택: 아이 사진 4장 · 견종 · 크기 등, 사진은 자동 분석) → 이메일 인증 → 가입 혜택 인증(건너뛰기 가능)
- **소셜 로그인 돌아옴** `/auth/social-callback`
- `/login` · `/signup` → `/auth/...` 로 이동 · `/forgot-password` 살아 있음
- **로그인이 필요해도 자동으로 로그인 화면으로 보내는 곳은 없음** — 모두 화면 안 안내 + 로그인 링크
  - 마이페이지 · 하위 · 주문 · 우리 아이 · 매일 댕생활 · 댕자랑 · 굿즈 공모전 · 추천 · 연구소 · 장바구니 결제 · 결제 화면 · 결제 확인 · 케어톡 사진 첨부

## 4. 쇼핑 (`/` · 상단바 · 장바구니 · 결제)
### 웹 홈 `/`
인트로 영상(앱에선 생략) · **히어로**(날씨 지역 선택, 견종 배지 → 펫렌즈 창) · 앱처럼 열기 · **맞춤 추천**(회원) · 베스트 · 브랜드(러프웨어 · 렉스스펙스) · 기획전(활동 · 비 · 눈 · 사료 · 묶음) · **매일 댕생활 맛보기** · 신상품 · 인스타그램
### 상단바(쇼핑 탭에서 보임)
- 왼쪽: 상품 뒤로(상품 상세, 모바일) · 로고 · 앱 홈
- PC 메뉴: 쇼핑(전체 · 베스트 · 신상 · 브랜드 · 묶음 · 카테고리) · 댕생활(보물광산 · 굿즈 공모전 · 우리 아이 기록 · 커뮤니티) · 댕자랑 · 고객센터 · 연구소
- 펫렌즈 버튼(모바일은 두 번 탭) · 국가·언어 · 검색(`/products?q=`, 최근 6개) · 장바구니 · 로그인/마이 · 메뉴(모바일)
### 장바구니 `/cart`
- 비었으면 상품 보러 가기 · 선택/전체선택/선택삭제 · 상품 → 상세 · **"어느 아이 것"** 선택(아이 없으면 회원 `/pet-lens` / 비회원 가입) · 수량 · 삭제 · 코인 적립 예상
- 테스트 주문서 / 토스페이 · 휴대폰 · 네이버페이(카카오페이 비활성) → 비회원은 로그인 화면
### 결제 `/checkout`
- 비회원: 미리보기만(결제 버튼 비활성) + 로그인하기
- 회원: 저장 배송지 선택 · 배송지 관리 · 배송비 계산 · 결제수단(카드 · 이체 · 토스페이 · 휴대폰 · 네이버페이) → 토스 **테스트** 결제
- 결제 성공: 결제 확인 → 주문 상세 `/mypage/orders/?orderId=` · 상품 보기 / 실패: 다시 결제 · 장바구니

## 6. 확인이 필요한 질문
1. 케어톡 서랍 `?q=` 자동 전송 막기 + `/chat?q=` 를 서랍 첫 질문으로 넘기기
2. 서랍 안 링크를 누르면 서랍 닫기
3. 앱에서 "챗봇에 문의" 상품 이름 전달
4. 네이티브 앱 번들 경로에 댕생활 · 댕자랑 · 쇼핑 · 장바구니 · 상품 추가 여부
5. 홈 탭을 시안(mockup-c)으로 갈지, 협업자 `/app/` 의 AI 케어 요약을 홈에 합칠지
6. 탭바 위로 올라와야 할 창들(검색 · 메뉴 · 국가 · 설치 안내 · 펫렌즈)
7. 로그인 여부 판단을 하나로 통일
