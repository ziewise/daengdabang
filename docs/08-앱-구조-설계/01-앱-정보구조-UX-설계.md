# 댕다방 앱 — 정보 구조 · 화면 · UX/UI 설계 v2 (로컬 시안, 배포 X)

> 범위: **앱 화면만.** 웹 화면은 그대로 두고, 앱 모드에서만 바뀐다.
> 근거: `docs/07-앱-화면-기능-전수분석/00~05` + 이 문서를 쓰며 코드에서 다시 확인한 사실(§1).
> 원칙: 협업자 코드는 수정하지 않는다(`export` 추가만). 서버를 새로 만들지 않는다. 확실하지 않은 것은 "확인 필요"로 표시한다.

## 0. 한 장 요약

- **탭:** 홈 · **연구소** · 댕다방 · 쇼핑 · 마이. 케어톡은 상단 버튼을 누르면 아래에서 서랍으로 올라온다.
- **세 축:**
  - **오늘** = 홈. 매일 댕생활의 출근도장, 할 일, 날씨.
  - **기록** = 연구소. 주간 사진 기록, 분석, 리포트.
  - **함께** = 댕다방. 댕자랑, 굿즈 공모전.
  - **코인**이 세 축을 잇는다.
- **화면 원칙:**
  - 한 화면은 두 화면 높이 이내.
  - 첫 화면에는 핵심 3개만.
  - 목록은 옆으로 넘긴다.
  - 할 일이 있을 때만 크게 보여 준다.
- **UI 콘셉트 "우리 아이가 사는 앱":**
  - 사용자 반려견의 **견종 3D 캐릭터**(앱에 이미 있는 155종)가 앱 안에서 산다.
  - 상태를 글 대신 **몸짓**으로 보여 준다: 기다림, 산책, 달리기, 킁킁.
  - 탭을 바꾸면 **탭바 위를 걸어서 이동**한다.
  - 하늘은 **실제 시간과 날씨**에 따라 코드로 그린다(영상 없음).

| 상태 | 캐릭터 |
|---|---|
| G | 처음 한 번 "함께할 아이를 골라 주세요"(인기 견종 6 + 검색) → 이 기기에 저장. 건너뛰면 토이 푸들 |

## 4. 화면 설계

> ▣ 첫 화면(스크롤 전) · ▤ 아래 줄(옆으로 넘기기) · 모든 줄은 내용이 있을 때만 보인다.

### 4-1. 홈 — 오늘

**첫 화면 구성(공통 뼈대):** ① 하늘 + 캐릭터 무대 → ② 오늘 카드 → ③ 신호 줄

#### 비회원(G)
| | 구역 | 내용 | 데이터 |
|---|---|---|---|
| ▣ | **하늘 무대** | 시간대 · 날씨에 맞춘 하늘 색, 빛, 비 · 눈 · 안개 효과. 캐릭터가 **다가오며 등장**(앞뒤 시트) → 서서 기다림. 한 줄: "서울 인근 · 맑음 18° · 산책하기 좋아요" | 날씨(로그인 불필요) |
| ▣ | **출근 스티커 체험** | 월~일 한 줄 보드 → 탭하면 쾅 → 캐릭터가 **달리기**로 좋아함 → 보드가 "로그인하면 내일도 이어져요 · 매일 {n}C"로 바뀜 | 화면 안에서만(저장 안 함) |
| ▣ | 가입 | "가입하고 20C 받기" · 이미 회원이에요(로그인) | `/auth/signup?redirect=` |
| ▤ | 케어톡 추천 질문 | 근처 동물병원 · 눈물 자국 · 오늘 산책 → 서랍이 열리며 바로 질문 | 비회원도 가능 |
| ▤ | 오늘의 댕자랑 | 실제 사진 4~6장 → 댕다방 | 피드(로그인 불필요) |
| ▤ | 이번 주 소식 | 굿즈 공모전 D-day("비회원도 참여 가능") · 댕주제 | 공모전 · 주제 |

## 6. UI · UX — "우리 아이가 사는 앱"

### 6-1. 왜 이 콘셉트인가
- **평범한 앱:** 카드와 아이콘에 글로 상태를 알려 준다. "출근 완료", "분석 중", "새 소식 3개".
- **이 앱:** **우리 아이 캐릭터가 몸짓으로 알려 준다.** 기다리고, 달리고, 걷고, 킁킁거린다.
- **귀엽고 친근함:** 지금 시안의 스티커와 같은 3D 결이라 분위기가 이어진다.
- **새로움:** 상태를 몸짓으로, 이동을 걸음으로 보여 주는 앱은 드물다.
- **재방문:** 내 아이 견종이 앱 안에 살고 있어서 "오늘도 보러 가고 싶은" 이유가 된다.
- **이미지 추가 없음:** 155견종 캐릭터가 이미 있다.

### 6-2. 캐릭터 몸짓 사전 (동작 시트의 줄 그대로)
| 몸짓 | 시트 | 의미 | 쓰는 곳 |
|---|---|---|---|
| 서기 | 동작 1줄 | 기다림 · 오늘 할 일이 있음 | 홈 무대 기본 |
| 걷기 | 동작 2줄 | 산책 · 이동 | 산책 할 일 완료, **탭 이동** |
| 달리기 | 동작 3줄 | 기쁨 · 축하 | 출근 도장, 할 일 모두 완료 |
| 킁킁 | 동작 4줄 | 살펴보는 중 | **연구소 분석 기다림**, 불러오는 중 |
| 다가오기 | 앞뒤 시트 아래 줄 | 반가움 | 앱 열기, 오랜만에 들어왔을 때 |
| 멀어지기 | 앞뒤 시트 위 줄 | 다녀오기 | 홈 → 매일 댕생활 전체로 들어갈 때 |

**절제 규칙:**
- 캐릭터는 **화면마다 한 마리, 한 곳**에만 둔다(무대 또는 탭바).
- 카드 안, 스티커 보드 안, 로그인 카드에는 넣지 않는다(이전 의견 반영).
- 말풍선은 쓰지 않는다. 의미는 몸짓과 옆의 한 줄 글로 전한다.

### 6-3. 대표 장면 8가지
| # | 이름 | 무엇 | 재방문 효과 |
|---|---|---|---|
| 1 | **탭바 산책** | 유리 탭바 위에 작은 캐릭터가 앉아 있다가, 탭을 바꾸면 **새 탭까지 걸어간다**(멀면 달림). 선택 표시도 함께 늘어나며 이동 | 앱의 얼굴. 탭을 누를 때마다 작은 즐거움 |
| 2 | **실시간 하늘** | 홈 무대의 하늘을 코드로 그림. 아침 복숭아빛 · 낮 하늘색 · 저녁 노을 · 밤 남색. 비 줄기, 눈송이, 안개, 바람에 날리는 잎은 가벼운 효과로. 기기를 기울이면 구름이 살짝 움직임 | 들어올 때마다 다른 화면 |
| 3 | **변신 카드** | 오늘 카드 하나가 스티커 보드 → 할 일 → 완료 장면으로 모양을 바꿈(요소가 끊기지 않고 이어짐) | 끝까지 하고 싶어짐 |
| 4 | **코인 비행** | 도장을 찍으면 코인이 포물선을 그리며 코인 칩에 들어가고, 숫자가 굴러 올라가며 칩이 한 번 통통 | 오늘과 연구소가 이어진다는 감각 |
| 5 | **내일 카운트다운** | 완료 장면에 "내일 새 스티커까지 7시간 12분"(서버의 다음 출근 시각) | 내일 다시 올 약속 |
| 6 | **성장 필름** | 주간 기록이 필름처럼 가로로 흐르고, 두 주를 끌어 겹치면 "새로 보임 / 이번엔 안 보임" 칩이 떠오름 | 한 칸씩 채우고 싶어짐 |
| 7 | **크레파스 응원** | 사진을 두 번 탭하면 크레파스 선으로 뼈다귀가 그려졌다 사라지고 기기가 살짝 진동 | 응원하는 재미, 받는 재미 |
| 8 | **주제 카드 뒤집기** | 새 댕주제가 시작되면 카드가 뒤집히며 등장, D-day 숫자가 굴러감 | 기간마다 새 이유 |

### 6-4. "앞으로의 트랜드" 해석
꾸밈을 늘리는 게 아니라 아래 네 가지다.
1. **살아 있음:** 실제 시간, 날씨, 우리 아이 상태에 따라 화면이 달라진다.
2. **동반자:** 기능이 아니라 우리 아이 캐릭터가 화면의 주인공이다.
3. **물성:** 유리 탭바, 깊이감, 스프링 물리, 기울기 반응, 진동.
4. **이어짐:** 카드가 화면으로 커지고, 코인이 날아가고, 캐릭터가 걸어간다. 요소가 끊기지 않고 이어진다.

### 6-5. 지킬 것 / 하지 않을 것
- **지킴:**
  - 따뜻한 중립 배경, 탭마다 다른 포인트 색, 얇은 테두리
  - Cafe24 써라운드(큰 글씨) · Wanted Sans(본문)
  - 스티커가 쾅 붙는 효과, 보드가 흔들리는 효과, 흐림 → 선명 등장, 스프링 전환
- **안 함:**
  - 말풍선 · 캡슐 · 젤리 · 지도 아이콘 · 반짝이
  - 검정 알약 탭
  - 카드 안 강아지 얼굴
  - 영상 배경
  - 정적인 이미지 교체만으로 끝나는 화면

### 6-6. 모션 · 성능 규칙
- **길이:** 작은 반응 180ms · 화면 전환 320~420ms · 축하 최대 900ms
- **캐릭터:** 시트를 한 칸씩 넘기는 방식, 초당 8~10장. 화면에 안 보이면 멈춘다.
- **움직이는 속성:** 위치 · 크기 · 투명도 · 흐림만 (60fps 유지)
- **동시에:** 큰 동작 2개까지
- **동작 줄이기 설정:** 캐릭터는 서 있기만, 전환은 짧은 페이드
- **진동:** 도장 · 응원 · 할 일 완료에만 짧게
- **이미지:** 포스터 약 40KB, 동작 시트 약 230KB를 처음 한 번만 받고 캐시

### 6-7. 기술
| 기능 | 방법 |
|---|---|
| 이어지는 전환 | View Transitions API(지원 안 되면 일반 전환) |
| 스크롤 등장 · 머리 줄어듦 | CSS 스크롤 연동 애니메이션(지원 안 되면 지금의 `useInView`) |
| 캐릭터 | 앱 전용 가벼운 스프라이트 부품(새로 작성, 웹 부품 안 씀) + `resolvePetProfileBreedId` 로 견종 연결 |
| 하늘 | CSS 그라데이션 + 가벼운 캔버스/CSS 효과, 날씨는 `fetchHeroWeatherReport` 결과만 사용 |
| 기울기 | DeviceOrientation(권한이 필요한 기기는 사용자가 허용할 때만) |
| 유리 | `backdrop-filter` + 얇은 하이라이트 테두리 |
