# 전용앱 AI 케어 허브 변경 로그

- 작업일: 2026-08-22 (KST)
- 적용 대상: 댕다방 자사몰 PWA `/app/`
- 스마트스토어 영향: 없음. 재고 1,708행 수령 전 상품 등록·게시 보류 유지

## 변경 내용

- 전용앱 홈에 반려견별 AI 케어 현황판 추가
- 최근 사진 분석, 주간 사진 변화, 행동·소리 관찰 기록을 한 화면에 통합
- 행동·소리 분석 엔진의 연결 상태 표시
- 일부 기록 API 실패 시 다른 기록을 유지하고 재시도할 수 있는 부분 실패 처리
- 재시도 중에는 확인한 기록을 유지하되 반려견을 바꾸면 이전 아이 기록이 섞이지 않도록 프로필 경계 적용
- 선택한 반려견을 사진 분석, 행동·소리 관찰, 주간 비교 화면까지 유지
- 관찰 결과가 의료 진단을 대신하지 않는다는 안전 문구 유지

## 검증

- ESLint: 변경 파일 통과
- Node 회귀 테스트: 456개 통과
- Next.js 16 프로덕션 빌드: 450개 정적 페이지 생성 및 TypeScript 검사 통과
- 브라우저 정적 DOM 1차 확인 완료. 로컬 QA 탭의 후속 로딩 완료 신호 지연은 앱 빌드 실패와 분리됨
