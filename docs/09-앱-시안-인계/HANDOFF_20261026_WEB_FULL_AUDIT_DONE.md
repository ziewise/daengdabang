## 3. 사장님 판단이 필요한 것(손대지 않음)

1. **세트 할인가가 장바구니에 반영되지 않음** — 중요
   - 세트 페이지는 '세트가 126,900원 · 10%'를 보여 줘요.
   - 그런데 '세트 한 번에 담기'를 누르면 장바구니에는 낱개 정가로 담겨요(`lib/shop.ts` 소계 = 단가 × 수량).
   - 손님에게 할인처럼 보이는데 실제로는 할인이 없어요. 둘 중 하나로 정해야 해요.
     - 기능 쪽에서 세트 할인을 넣는다.
     - 화면에서 할인 표시를 뺀다.
2. **'오픈 준비 중'인데 장바구니에서는 테스트 결제창까지 진행돼요.**
   - 상품 상세는 '주문은 정식 오픈 후에 만나요'라고 안내해요.
   - 장바구니 '테스트 주문서' 단추로는 결제창이 열려요. PG 심사 중이라 그대로 뒀어요.
3. **심사용 · 테스트 문구** — PG 심사가 끝나면 정리해요.
   - 대상: FAQ '심사용 계정', 마이페이지 '테스트 결제완료', 주문 내역 '화면 검증용', 비회원 조회 '연동 준비 중'
   - FAQ는 앱도 같은 내용을 써서 그대로 뒀어요.
4. **공지사항 날짜** — 전부 2026년 6월이고, 10월인데 '여름철 배송 일정' 공지가 보여요(내용 자료라 그대로 둠).
5. **앱과 같이 쓰는 문구의 합니다체** — 예: '장바구니가 비어 있습니다.', 주문서 오류, 비밀번호 '72바이트' 안내. 앱 문구도 같이 해요체로 바꿀지 정해야 해요.
6. **기능 쪽 참고**
   - 주문서에 주소 검색 단추가 없음(우편번호 직접 입력)
   - 세트 담기는 색상 · 사이즈 없이 담김
7. **안 쓰는 파일**(화면 영향 없음, 정리할지 선택)
   - `app/(auth)/login/LoginForm.tsx`, `SignupForm.tsx`, `MypageGuestGate.tsx`
   - `app/chat/ChatPageClient.tsx`, `ChatbotModal`, `components/site/Header.tsx` · `Footer.tsx`
8. **홈 맨 위 큰 제목** — 주아체가 아님(영상 위 협업자 영역이라 그대로 둠).
