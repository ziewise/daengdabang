# 자사몰 상품 후기(리뷰) 기능 — 정리안 (2026-10-25, DRAFT)

> 지금 사이트의 상품 후기는 **외부 판매처(네이버 등) 후기 + AI 요약**을 보여주기만 한다.
> 고객이 직접 쓰는 **댕다방 구매 후기**가 없다 → 새로 만든다.
> 서버(저장 · 구매자 확인 · 적립 · 관리)는 협업자, 화면은 우리(웹 · 앱) 담당.

---

## 1. 확정된 결정

| 항목 | 결정 |
|---|---|
| 진행 방식 | **단계적** — 1단계 일반 · 포토 후기, 2단계 영상 추가 |
| 작성 창 | 하나의 창 안에 탭 두 개: **일반 후기**(글만, 업로드 단추 없음) / **포토 후기**(사진 1장 이상 필수) |
| 첨부 | 사진 최대 **5장** (2단계: 영상 최대 **1개** 추가) |
| 작성 자격 | **실제 구매자만** — 배송 완료된 주문의 상품마다 후기 1개 |
| 작성 기한 | **배송 완료일**부터 **90일** |
| 적립금 | 일반 · 포토 **같은 금액**, 현재 정책 "리뷰 작성 2배 적립" 유지. 후기 종류(일반 · 포토 · 영상)별 금액을 **관리자가 따로 바꿀 수 있게** 설정값으로 |
| 공개 | 작성 즉시 **바로 공개** |
| 작성자 이름 | **일부 가림** (예: 김\*댕) |
| 영상 소리(2단계) | 음소거 — 저장할 때 **소리를 지워서** 보관(목소리 개인정보 · 용량) |

---

## 2. 단계

### 1단계 — 먼저 오픈
- 일반 후기 · 포토 후기(사진 5장)
- 화면에 영상 자리는 미리 만들되 숨김

### 2단계 — 곧이어
- 영상 1개 추가: **30초 이하**, 용량 제한(예: 100MB), mp4 · mov, 소리 제거, 썸네일 자동 생성
- 신고 들어오면 즉시 숨김 → 관리자 확인
- 영상 후기만 "확인 후 공개"로 바꿀지 그때 다시 결정

---

## 3. 화면 (우리 · 웹 + 앱)

### 3-1. 들어가는 곳
- **마이페이지 주문 내역** — 배송 완료 상품마다 "후기 쓰기"(가장 많이 씀). 이미 쓴 상품은 "내 후기 보기 · 수정"
- **상품 상세** — "후기 쓰기" 단추. 쓸 수 있는 구매자에게만 열림, 아니면 "구매 후 작성할 수 있어요" 안내
- 배송 완료 며칠 뒤 알림(메일 · 앱 알림) → 바로 작성 창
- 한 주문에 여러 상품이면 "후기 쓸 상품 N개" 안내

### 3-2. 작성 창 (모달, 휴대폰은 아래에서 올라오는 판)
- 머리: 상품 사진 · 이름 · **구매한 옵션**(색상 · 사이즈) 자동 표시
- 탭: 일반 후기 | 포토 후기 — **탭을 바꿔도 쓰던 글은 그대로**
- 별점 1~5
- 짧은 항목 평가(분류별): 의류 "사이즈 작아요 · 딱 맞아요 · 커요", 먹거리 "잘 먹어요 · 보통 · 안 먹어요" 등
- **우리 아이 정보** — 견종 · 몸무게 · 고른 사이즈를 펫 프로필에서 자동 채움(고칠 수 있음)
- 내용(최소 · 최대 글자 수)
- 포토 탭: 사진 올리기(최대 5장 · 미리보기 · 순서 바꾸기 · 하나씩 지우기 · 올리기 진행 막대 · 실패 시 다시 올리기), 사진 자동 줄이기(기존 기능 재사용)
  - 사진 0장이면 등록 단추 막고 "사진을 1장 이상 올려 주세요"
  - 사람 얼굴 · 연락처 등 개인정보 사진 안내
- 적립 안내 한 줄("작성하면 ○○원 적립")
- 등록 → 완료 화면(적립 안내) → 상품 후기 목록에 바로 보임

### 3-3. 상품 상세 후기 구역
- **"댕다방 구매 후기"와 "외부 판매처 후기"를 탭(또는 구역)으로 분리** — 출처를 섞지 않음
- 평균 별점 · 별점 분포 · 후기 수
- 포토 후기 모아보기(사진 줄)
- 정렬: 최신 · 별점 높은/낮은 · 도움돼요 많은
- 필터: 포토 후기만 · 비슷한 아이(견종 · 사이즈)
- 후기 카드: 가린 이름 · 별점 · 구매 옵션 · 우리 아이 정보 · 항목 평가 · 글 · 사진(누르면 크게 보기) · "도움돼요" · 신고 · **판매자 답글**
- 상품 목록 카드에도 별점 · 후기 수

### 3-4. 마이페이지
- 내가 쓴 후기 목록(수정 · 삭제) · 쓸 수 있는 후기 목록(남은 기한 표시)

---

## 4. 서버 (협업자)

- 후기 저장 · 불러오기 · 수정 · 삭제(상품별 목록 · 정렬 · 필터 · 쪽 나누기)
- **작성 자격 확인**: 배송 완료 주문 상품 · 90일 이내 · 1개만
- 사진 저장(2단계: 영상 저장 · 변환 · 소리 제거 · 썸네일)
- 이름 일부 가림
- 적립금 지급 — 종류별 금액 설정값, 지급 시점
- 도움돼요 · 신고 · 숨김 · 판매자 답글
- 관리자 화면: 후기 목록 · 검색 · 숨김 · 신고 처리 · 답글 · 적립 설정
- 상품별 평균 별점 · 후기 수(목록 카드용)

---

## 5. 아직 정할 것

| 항목 | 메모 |
|---|---|
| **기본 적립금** | "2배"의 기준 금액(예: 500원 → 1,000원) |
| 교환 · 반품 · 환불된 상품 | 후기를 막을지, 이미 쓴 후기 · 적립금 처리 |
| 후기 삭제 시 적립금 | 회수할지 |
| 비회원 주문 | 후기 허용 여부 |
| 같은 상품의 다른 색상 · 사이즈 | 후기를 한곳에 모을지 |
| 글자 수 | 최소 · 최대(예: 10자 이상 · 1,000자 이하) |
| 항목 평가 종류 | 분류별 질문 확정 |
| 기본 정렬 | 최신순 또는 도움돼요순 |

## 6. 확인 필요 (전문가 · 공정위 기준)
- 적립금을 주는 후기의 표시 의무(추천 · 보증 심사지침)
- 부정적 후기를 임의로 숨기거나 지우면 안 된다는 규정 — 숨김은 신고 · 운영 기준에 따른 것만
- 사진 · 영상 속 개인정보 처리

## 7. 연결하면 좋은 것(선택)
- 포토 후기 사진을 **댕자랑에도 함께 올리기** 선택
- 첫 후기 이벤트
- 앱(스티커북)에도 같은 기능
