## 1. 먼저 알아 둘 것 — 웹과 앱은 어떻게 같이 움직이나

1. **기능(서버 요청)은 웹과 앱이 같은 코드**를 씁니다(같은 저장소 `ziewise/daengdabang`, 같은 함수 · 같은 스위치).
   → 서버 작업을 끝내고 스위치를 켜면 **웹과 앱이 함께** 켜집니다. 앱 화면에도 같은 단계 · 단추를 이미 넣어 두었습니다(앱 가입 `StickerSignup.tsx` 도 `NEXT_PUBLIC_SIGNUP_IDENTITY` 를 읽음).
2. **화면은 따로** 그려집니다. 앱에서 열면 `html.ddb-app-mode` 로 앱 전용 화면(스티커북 결)이 나옵니다. 그래서 웹에 새 단추를 만들면 앱 화면에도 따로 넣어야 하는데, 아래 표의 기능은 **10-26 까지 앱에도 모두 넣었습니다.**
3. **스위치는 빌드할 때 굳어집니다**(`NEXT_PUBLIC_*`). 켜는 곳: `.github/workflows/deploy.yml` 빌드 `env:` 에 줄을 더하고 GitHub 저장소 변수(vars)에서 `1`.
   - **지금 `deploy.yml` 에는 아래 스위치 줄이 하나도 없습니다 → 운영에서는 모두 꺼짐.**
4. **앱에 담긴 페이지는 앱 업데이트가 필요합니다.** 앱(Capacitor)은 일부 페이지를 앱 안에 복사본으로 담습니다(`scripts/prepare-native-web.mjs` — `app · auth · cart · chat · legal · my-pet · mypage · offline · pet-lens · petlens · privacy · terms`, 약 38MB).
   - **담긴 페이지**(로그인 · 가입 · 마이페이지 · 장바구니 …): 웹 배포만으로는 설치된 앱이 안 바뀜 → **앱 새로 빌드 · 업데이트**
   - **안 담긴 페이지**(상품 · 주문서 `checkout` · 결제 결과 · 비회원 주문 조회 `order-lookup` · 비밀번호 찾기 웹 주소 …): 앱이 실제 사이트를 불러옴 → **웹 배포하면 앱도 바로**

## 4. 협업자 10-30 토스 배포(`0fcc1812`)와의 관계 — 대조 결과

- 운영 main 은 `8e3665c9`(우리 10-29) → **`0fcc1812`(협업자 10-30)**. 우리 작업 브랜치도 이 커밋으로 맞췄습니다(겹친 파일 없음 · 빨리감기).
- **주문 내역 환불 표시**(협업자): `app/mypage/orders/page.tsx` · `lib/toss-order-history.ts` — 이 페이지는 웹과 앱이 같이 쓰므로 **앱에서도 환불 상태가 보입니다**(앱은 업데이트 후).
- **주문 취소**: 협업자 정책은 "관리자만 · 전액만 취소, 고객이 직접 신청하는 취소는 아직 없음".
  → 우리 화면의 **"주문 취소 요청"은 1:1 문의로 접수**되므로 지금 정책과 맞습니다(고객 요청 → 운영자가 관리자 취소 API 로 처리).
  → 나중에 고객이 직접 신청하게 하려면 기존 문서 5-① `POST /api/v1/payments/toss/orders/{orderId}/cancel-request` 를 만들고, 창의 접수만 바꾸면 됩니다. 이때 협업자가 만든 취소 기록 값(`cancel: { status, requestedAt, refundedAmount, remainingAmount, refundedAt }` · `cancel_pending` · `refunded` · `partially_refunded`)을 그대로 쓰면 됩니다 — 우리가 5-④ 에서 제안한 `cancel?: { status, requestedAt }` 와 같은 자리입니다.
- **정식 오픈 전 잠금 창**: 결제 잠금은 협업자 `PrelaunchNoticeModal`(결제 단추를 누를 때), 첫 방문 안내는 기존 `PrelaunchNotice`(사이트 첫 방문 팝업) — 둘 다 있고 역할이 다릅니다. 사이트 미리보기(`ddbPreview`)에서는 첫 방문 안내만 띄우지 않습니다.
- **비회원 결제**: 협업자 문서대로 로그아웃 손님은 지금 결제 불가(7번 스위치 꺼짐) — 정식 오픈 전 잠금과 별개로 원래 막혀 있습니다.
